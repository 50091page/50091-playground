# 50091 프로젝트 개요

## 요약

`50091`은 Vite + React + TypeScript 기반의 게임 도구 모음이다.

1. **팀 섞기**: 리그 오브 레전드, 배틀그라운드, 오버워치 팀 편성 및 오버워치 맵 추첨
2. **에임 훈련장**: PixiJS로 렌더링되는 반응 속도 훈련
3. **반응속도 테스트**: 색이 바뀐 후 입력까지 걸리는 시간을 5회 측정
4. **우주의 시계**: 흐른 시간과 천체의 누적 이동 거리, 빛이 갔을 거리를 글과 숫자로 관찰

펭귄 관찰소는 소스와 이미지가 있는 로컬 개발 서버에서만 열 수 있다. 시안 파일은 공개 저장소와 운영 사이트에 포함하지 않는다.

사다리타기는 카드와 메뉴만 남겨 둔 비활성 기능이다. 앱은 백엔드, 인증, 서버 저장소 없이 동작한다. 팀·맵 설정, 사용자 지정 테마, 반응속도 개인 최고 기록, 우주의 시계 출발 시각은 브라우저 `localStorage`를 사용한다. 훈련 및 측정 세션 자체는 메모리에서 관리한다.

## 기술 스택

- 런타임: React 18
- 빌드 도구: Vite 5
- 언어: TypeScript
- 라우팅: `react-router-dom` + `HashRouter`
- 상태 관리: 에임 트레이너에 Zustand 사용
- 렌더링: 일반 DOM UI + `@pixi/react` 기반 PixiJS
- 스타일링: 공유 CSS 중심, Tailwind 기본 스타일과 유틸리티 사용

### 공통 헤더

- 메인과 도구 페이지 모두 `기존` 시안인 전체 너비의 플랫 헤더를 사용한다. 배경은 반투명이고 하단에만 옅은 `1px` 구분선을 둔다.
- 내부 기준 폭은 본문과 같은 최대 `1120px`이다. 왼쪽 `50091` 브랜드는 홈 링크, 오른쪽 캐릭터 버튼은 라이트·다크 전환이다.
- PC 헤더는 하단선을 포함해 기본 `64px`이다. 메인에는 상위 메뉴를 표시하지 않는다. 모든 도구 페이지는 팀 섞기, 에임 훈련장, 반응속도 테스트, 비활성 사다리타기 메뉴를 공유하고 현재 경로를 강조한다. 좁은 화면에서는 메뉴를 브랜드와 테마 버튼 아래로 내리고, 폭이 더 좁으면 두 열로 배치한다.
- 개발 모드의 메인에서만 `기존`, `A 플로팅`, `B 플랫` 시안을 전환할 수 있다. 초기값은 `기존`이고, 개발용 선택기와 스타일은 프로덕션 번들에 포함하지 않는다. 도구 페이지에는 A·B가 적용되지 않는다.
- 시안 파일: `src/dev/HeaderPreviewControls.tsx`, `src/dev/header-preview.css`.

### 공통 배경

- 홈의 기존 배경이 사이트 전체의 기준이다. 테마별 바탕과 그라데이션(다크 모드의 왼쪽 위 블루 바이올렛 광원 포함)은 `workspace.css`에서 관리한다. 파도와 펭귄 발자국은 `WorkspaceBackground`가 라우트 바깥에서 한 번만 렌더링한다.
- 배경 장식은 콘텐츠 뒤, 푸터 바로 위에 배치되고 입력을 가로채지 않는다.
- 기존 및 새 페이지는 공통 배경을 자동으로 상속한다. 페이지 전체 배경을 별도로 정의하거나 장식을 복제하지 않는다. 카드, 캔버스, 반응속도 테스트의 빨강·초록 자극은 자체 배경을 유지한다.

### 공통 푸터

- 모든 페이지 하단에 `Made by 저둥저둥`을 표시한다. 기존 글꼴, 색상, 여백, 좌측 정렬과 상단 구분선을 유지한다.

## 페이지

### 메뉴

파일: `src/pages/MenuPage.tsx`

- 넓은 화면에서는 왼쪽에 상위 제목 없는 **팀 섞기** 카드, 오른쪽 `연습·미니게임` 아래에 **에임 훈련장**, **반응속도 테스트**, **사다리타기** 카드를 배치한다. 좁은 화면에서는 팀 섞기가 위로 오고 미니게임 목록이 아래에 이어진다.
- 카드 기본 높이는 `136px`, 모서리 반경은 `22px`이다. 팀 섞기만 펭귄 이미지와 `팀 편성 · 맵 추첨` 부제목을 사용한다. 부제목은 기본 `13px`로 제목 아래 `5px` 띄운다. 미니게임 카드는 제목과 아이콘만 표시한다.
- `힐링`은 기존 기능 영역 아래에 배치하고, 넓은 화면에서는 `연습·미니게임`과 열을 맞춘다. 공통 헤더에는 넣지 않는다. 우주의 시계는 궤도 아이콘, 개발 전용 관찰소는 기존 마스코트를 사용한다.
- 활성 카드는 실제 링크여서 `Enter`로 이동할 수 있다. `LADDER_DISABLED`가 켜져 있는 동안 사다리타기는 카드와 상위 메뉴에 흐리게 표시되며, 링크 없이 `aria-disabled="true"`를 노출한다. 공용 목록은 활성 항목을 먼저, 비활성 항목을 뒤에 두고 각 그룹 안의 순서는 유지한다.

### 셔플

파일: `src/pages/ShufflePage.tsx`

- 본문 상단에서 리그 오브 레전드(기본), 배틀그라운드, 오버워치를 전환한다. 선택한 게임 카드만 보인다.
- LoL과 PUBG는 중앙에 단일 카드, 오버워치는 PC에서 팀 섞기와 맵 추첨을 두 열로 배치한다. 좁은 화면에서는 오버워치 두 카드가 세로로 쌓인다.
- 패널은 전환 시 제거하지 않고 숨긴다. 입력·잠금·맵 설정과 진행 중인 작업이 타이머 종료까지 유지된다.
- 자세한 규칙은 [팀 섞기 기능 명세서](01_shuffle_tool_spec_ko.md) 참고.

### 에임 트레이너

파일: `src/pages/AimTrainerPage.tsx`

- Pixi 캔버스 플레이필드를 렌더링한다
- HUD, 시작/일시정지/종료 오버레이, 옵션 패널, 오디오 재생을 담당한다
- 게임 세션 상태는 Zustand 스토어를 단일 소스로 사용한다
- 상단 `50091` 링크로 메인에 돌아간다. 자세한 규칙은 [에임 훈련장 명세](02_aim_trainer_spec_ko.md) 참고.

### 반응속도 테스트

색 자극에 대한 입력 지연을 브라우저 안에서 5회 측정하고 입력 방식별 최고 평균을 저장한다. 자세한 규칙과 측정 한계는 [반응속도 테스트 명세](03_reaction_time_spec_ko.md) 참고.

## 공통 앱 동작

### 테마

파일:

- `src/hooks/useTheme.ts`
- `src/utils/storage.ts`

동작 규칙:

- 테마 값: `light` 또는 `dark`
- 저장 키: `soopi-utils.theme`
- 첫 진입 시:
  - 저장된 테마가 있으면 그 값을 사용
  - 없으면 `prefers-color-scheme`를 따른다
- 사용자가 한 번이라도 토글하면 이후부터는 `localStorage`에 고정 저장된다
- 테마는 아래 두 방식으로 DOM에 반영된다
  - `document.documentElement.dataset.theme`
  - 루트 요소의 `dark` 클래스

### 저장소 안전 처리

`safeLocalStorageGet`, `safeLocalStorageSet`은 `try/catch`로 감싸져 있어 브라우저 저장소 접근이 실패해도 앱이 죽지 않는다.

## 테스트 범위

현재 자동화 테스트는 별도 테스트 프레임워크가 아니라 TypeScript로 작성된 커스텀 러너를 `npm test`로 실행하는 구조다.

포함된 영역:

- 셔플 스왑 공정성 및 불변 조건
- 스왑 툴 보조 함수
- 중복 이름 정규화 로직
- 오버워치 맵 후보 계산 및 저장 상태 마이그레이션
- 반응속도 타임스탬프 호환성, 조기 입력, 중복 입력, 중단, 세션 통계 및 정리
- 우주의 시계의 시간 계산, 행성 기준점, 갱신 주기 및 초기화 저장

자동 테스트가 없는 영역:

- React UI 렌더링 동작
- 라우트 이동
- 테마 토글 상호작용
- 에임 트레이너 Pixi 상호작용 및 타이밍 루프

게임 탭의 레이아웃, 키보드 이동, 탭 전환 전후 입력·잠금·맵 추첨 결과 보존은 브라우저에서 수동으로 검증했다.

## 빌드와 실행

### 스크립트

- `npm run dev` -> Vite 개발 서버
- `npm run build` -> TypeScript 빌드 + Vite 프로덕션 빌드
- `npm run preview` -> 빌드 결과 미리보기
- `npm test` -> 커스텀 TypeScript 테스트 컴파일 및 실행

### 배포 형태

- 정적 프런트엔드
- `.github/workflows/deploy.yml`은 `main` 푸시 또는 수동 실행 시 `dist`를 GitHub Pages에 배포하도록 설정되어 있다.
- 커스텀 도메인 설정: `public/CNAME`의 `50091.xyz`.
- `HashRouter`를 사용하므로 정적 호스팅 환경에서도 라우팅이 안정적이다
